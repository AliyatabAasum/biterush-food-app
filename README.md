# 🍔 BiteRush - Food Ordering App

> **Fresh, hot, and delivered to your door 🚀**

A modern, full-stack food ordering web application built with **React + Vite**, featuring a sleek dark UI, real-time cart management, wishlist, and admin panel.

## ✨ Features

- 🍔 **Browse Menu** — Filter by category: Burgers, Pizza, Asian, Healthy, Drinks, Desserts
- 🔍 **Search Dishes** — Instant search across all menu items
- ❤️ **Wishlist** — Save your favourite items
- 🛒 **Cart System** — Add items, manage quantities, view total
- 📦 **Orders** — Track your placed orders
- 🔧 **Admin Panel** — Manage menu items and orders
- ⭐ **Ratings & Reviews** — Each dish shows ratings and review count
- 📱 **Responsive Design** — Works on mobile and desktop
- 🌙 **Dark Theme** — Beautiful dark UI with orange accents

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/AliyatabAasum/biterush-food-app.git

# Navigate to project folder
cd biterush-food-app

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
```
